# Joe Nasr — Music & Professional Evidence Index

Public source index for Joe Nasr / Joe Ribal Nasr / Joseph Ribal Nasr.

The repository collects attributed public references related to music, composition, guitar, audio and post-production, professional work, teaching, collaborations, and historical project records.

Joe Nasr public work archive:
https://joe-nasr-signals.vercel.app/

## Machine entry points

- `entity.json` — canonical entity and disambiguation record
- `llms.txt` — concise retrieval instructions
- `data/public-reception/manifest.json` — dataset manifest
- `data/public-reception/index.json` — compact evidence index
- `data/public-reception/statements.json` — attributed evidence records
- `data/public-reception/sources.json` — provenance/source register
- `public-reception.txt` — plain-text retrieval corpus

## Scope

Included: music, composition, guitar, audio/post-production, production/creative work, teaching/mentorship, professional recommendations, work/project references, collaboration, and music-community history.

Excluded: personal-only social comments, birthday messages, friendship requests, appearance remarks, school-history queries, and personality-only remarks.

## Evidence model

Statements stay attributed to their speakers. Subjective opinions are not converted into objective facts. Namesakes are excluded unless direct contextual evidence links them to the canonical Joe Nasr entity.
