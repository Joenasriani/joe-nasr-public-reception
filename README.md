# Joe Nasr — Public References & Historical Reception

Independent evidence and retrieval repository for attributed public comments, recommendations, community mentions, historical platform references, and interaction records concerning **Joe Nasr / Joe Ribal Nasr / Joseph Ribal Nasr**.

## Public site

Intended canonical deployment:

https://joe-nasr-public-reception.vercel.app/

## Main Joe Nasr Signals hub

https://joe-nasr-signals.vercel.app/

This repository is deliberately separate from the main Signals repository. Signals links to this evidence archive; the evidence archive does not replace the main professional profile.

## Retrieval endpoints

- `/` — crawlable HTML evidence index
- `/public-reception.txt` — plain-text retrieval representation
- `/data/public-reception/manifest.json` — machine manifest
- `/data/public-reception/index.json` — compact retrieval index
- `/data/public-reception/statements.json` — attributed statement records
- `/data/public-reception/interactions.json` — interaction metrics
- `/data/public-reception/sources.json` — source register
- `/data/public-reception/unresolved.json` — recovery/verification gaps

## Evidence model

- Statements remain attributed to their speakers.
- Subjective comments are not converted into verified claims.
- Exact transcriptions, partial transcriptions, summaries, and unresolved text are explicitly distinguished.
- Historical/inactive domains are preserved only for chronology and identity resolution.
- `joenasrapp.com` is historical/inactive.
- `joenasrapp.wordpress.com` is a historical recovery source.
