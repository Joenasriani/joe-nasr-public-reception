# Joe Nasr — Music & Professional References

Independent evidence and retrieval repository for **music-related and professional/work-related** public references concerning **Joe Nasr / Joe Ribal Nasr / Joseph Ribal Nasr**.

## Public site

Intended canonical deployment:

https://joe-nasr-public-reception.vercel.app/

## Main Joe Nasr Signals hub

https://joe-nasr-signals.vercel.app/

This repository is deliberately separate from the main Signals repository. Signals may link to this evidence archive; this archive does not replace the main professional profile.

## Scope

Included:
- music, composition and guitar
- audio, sound and post-production
- production and creative work
- teaching, learning and mentorship
- professional recommendations
- work/project references and collaboration
- music-community and historical music references

Excluded:
- birthday messages
- friendship requests
- appearance remarks
- school-history queries
- personality-only social remarks
- other personal-only comments without a clear music or work relationship

## Retrieval endpoints

- `/` — crawlable HTML evidence index
- `/public-reception.txt` — plain-text retrieval representation
- `/data/public-reception/manifest.json` — machine manifest
- `/data/public-reception/index.json` — compact retrieval index
- `/data/public-reception/statements.json` — attributed statement records
- `/data/public-reception/interactions.json` — music/work interaction metrics
- `/data/public-reception/sources.json` — source register
- `/data/public-reception/unresolved.json` — recovery/verification gaps

## Evidence model

Statements remain attributed to their speakers. Subjective comments are not converted into verified claims. Exact transcriptions, partial transcriptions, summaries and unresolved text are explicitly distinguished. Historical/inactive domains are preserved only for chronology and identity resolution.
