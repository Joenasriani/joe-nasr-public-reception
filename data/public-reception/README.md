# Music & Professional Reception Data

This directory stores retrieval-oriented records about public statements, interactions, platform descriptions and historical source material concerning Joe Nasr / Joe Ribal Nasr / Joseph Ribal Nasr.

## Scope

Only music-related and professional/work-related material is included: music, composition, guitar, audio, production, teaching/mentorship, professional recommendations, project/work references, collaboration and music-community history.

Personal-only social comments are excluded.

## Files

- `statements.json` — atomic music/work-related third-party statements.
- `interactions.json` — music/work-related interaction metrics.
- `sources.json` — source register.
- `unresolved.json` — recovery and verification gaps.
- `manifest.json` — canonical machine-readable dataset manifest.
- `index.json` — compact retrieval index with stable anchors.
- `/` — crawlable landing page.
- `/public-reception.txt` — plain-text retrieval endpoint.

## Evidence rules

- Preserve each statement as its own record.
- Preserve exact wording where readable; otherwise mark summaries or partial transcriptions explicitly.
- Keep namesakes excluded unless contextual evidence supports identity linkage.
- Historical or inactive domains remain historical evidence only.
- `joenasrapp.com` is inactive and must not be presented as a current destination.
- `joenasrapp.wordpress.com` is a historical recovery source.
- Source inclusion documents the public record; it does not imply endorsement or independent verification of subjective claims.
